Photos artisanat (sources utilisateur).

Format .jfif = JPEG (compatible navigateurs). Pour le site, lancez :

    python3 scripts/deploy-artisanat-images.py

Le script convertit et recadre les images vers assets/images/culture-gbe/
(hero-culture, arts-artisanat, sous-thèmes artisanat, galerie, etc.).

Les originaux .jfif restent ici comme archive.
