Remplacez les fichiers JPEG ci-dessous par les portraits officiels (carré ou 3:4, min. 400×400 px) :

  patrice-houinato.jpg       — Patrice HOUINATO

Après remplacement des fichiers :
  1. WordPress Admin → GbeCosmoLingua → « Synchroniser les photos des fondateurs »
     (ou réactivez le plugin pour lancer la mise à jour automatique)
  2. Ou définissez une « Image mise en avant » sur chaque fiche Membre dans l’admin.

Les photos sont importées dans la médiathèque lors de la synchronisation.
